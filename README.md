## Community guidelines

[BookClub Kulüp Kuralları](community-guidelines.md) is the Turkish agreement displayed before joining a club in the iOS app.

The app loads this UTF-8 Markdown file from the `main` branch. Keep the top-level title, version/date paragraph, and `##` section headings; separate paragraphs with a blank line. Update the version and date when changing the rules. The app requires the reader to explicitly accept the loaded text before submitting a new club membership request.
